MUNEEB UL HASSAN — PORTFOLIO WEBSITE

HOW TO USE
1. Keep index.html, store.html, style.css, script.js and the assets folder together.
2. Open index.html in a browser to view the portfolio.
3. Use the Add project button to add projects. Added projects are saved in that browser's local storage.
4. Project Store is a separate page (store.html), separate from the main portfolio.

BEFORE PUBLISHING
- Replace the sample project cards with your completed work and real images.
- Add your preferred professional social/profile links if you want them.
- The Project Store is a visual storefront preview only. It does not accept payments or deliver files.
  To sell projects, connect a secure payment provider and a file-delivery process.
- The contact email is taken from the supplied CV. Remove or change it if you prefer not to publish it.
- Upload the whole folder to your hosting provider; do not upload only index.html.
